# Aikatest

Projetos do Aika reunidos em um só repositório.

| Pasta | O que é |
|---|---|
| [AikaEmu](AikaEmu) | Emulador do servidor (Auth, Game e Web) em C# .NET 8. Já corrigido para rodar em Linux/Windows com MySQL 8 ou MariaDB. Tutorial: [AikaEmu/docs/TUTORIAL-LOCAL.md](AikaEmu/docs/TUTORIAL-LOCAL.md) |
| [TheLastJourney](TheLastJourney) | Esboço antigo de GameServer (.NET Core 2.0). A senha do banco em `Bin/Config.json` foi removida; preencha a sua localmente. |
| [Sistema-Gerenciador](Sistema-Gerenciador) | Aplicação Java (NetBeans/Swing) de cadastro com conexão MySQL. |
| [Aika-Last-Journey](Aika-Last-Journey) | Apenas README e licença. |

Origem: repositórios `aikalastjourney/AikaEmu`, `TheLastJourney`, `Sistema-Gerenciador` e `Aika-Last-Journey`.
